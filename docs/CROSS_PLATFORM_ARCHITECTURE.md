# 跨端架构约定

JobPilot 保留现有 H5 登录和页面，同时为微信小程序增加独立展示层。两端不得复制岗位搜索、邮箱核验、匹配评分或邮件投递逻辑。

## 分层

```text
H5 / 小程序 UI
       ↓
统一 API 契约（src/shared/api-contract.ts）
       ↓
服务端业务层、岗位库、数据库、投递队列
```

当前 H5 继续使用签名 httpOnly Cookie。小程序接入时增加独立的微信会话适配器，但调用相同资源接口，并在服务端把微信身份绑定到现有用户账户。任何邮件密钥、数据库字段和简历原文都不得进入小程序包。

## 统一资源

两端共享 `/api/state`、简历、偏好、匹配、岗位选择和投递接口。稳定的最小类型与错误结构位于 `src/shared/api-contract.ts`；新增接口必须先补契约和测试，再接入任一前端。

## 不影响现有网页登录

- 不改变现有邮箱登录路由和 Cookie 名称。
- 不把小程序 Token 写入 Web Cookie。
- 不让小程序绕过岗位库的新鲜度、来源状态或用户投递确认。
- 不在客户端实现权限判断的唯一版本；服务端始终重新校验用户归属。
